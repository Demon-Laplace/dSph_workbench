# 旧代码备查归档（不参与运行同步）

这里保存用户明确要求保留备查的旧源码，不是可运行的代码库。
生产模型统一调用已激活的 `workspace/code/production/`；isolation 保持独立共享代码。

- 本目录不在 `workflow_github.source_files()` 的源码同步白名单中。
- 发布器仅打包 `repo/`、`workflow/`、`IniFile/`，不会将本目录装入运行环境。
- IC工具和服务器源码checkout稀疏排除本目录；需要备查时直接从GitHub下载。
- `.gitattributes` 同时将其排除于普通 `git archive` 导出。
- 不自动恢复到模型目录，不改写既有冻结运行或不可变release。
