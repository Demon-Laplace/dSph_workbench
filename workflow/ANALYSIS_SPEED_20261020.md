## 修改与不变量

- `snapshot_io.py`：坐标、速度分别整块读取一次，再填入原有 float32 列；
  避免每个向量三个分量分别扫描 HDF5。uint64 ID、质量精度、行序及所有字段保留。
- `canonical_observer.py`：两组 ID 已分别通过唯一性检查；用一次成员掩码同时
  得到缺失数，保留空 cohort、重复 ID、缺失 ID 和类型错误时拒绝执行的保护。

不改变 `astropy_native_direct_v1`、物理配置 SHA
`e7fd3ff559ba72ba8fed4bc4b149a403cbdd137a4ed4a7b986e5ee357ae9fde2`、
TAN 显示合同 `heliocentric_tan_xi_eta_2p1_v1` 或显示窗口、像元面积和箭头。
动力学仍使用当前 old+new 成员；冻结 old cohort 仍用于光度参考。
轨道候选不应用，模拟、原始快照、IC、既有图片视频和用户 shell 不改动。
源码 SHA 改变后必须准备新分析，不能混用旧 PNG 的显示身份。
